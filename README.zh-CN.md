## 产品与实验

- 🎨 **[Skillry](https://skillry.dev/)** — 有审美的 AI Skill 市场，帮助用户发现、预览和安装实用的 Agent Skills，让 AI Agent 制作好看、实用的演示、网站、视频与图片。

- 🎞️ **[MkBoard](https://mkboard.app/)** — 桌面端分镜 Agent，把脚本转成可编辑的镜头规划与生成式 B-roll 素材。
- ✨ **[MkAnime](https://mkanime.ai/)** — 一站式 AI 动漫生产平台，覆盖剧本、分镜、角色、配音与导出。
- 🧑‍💻 **[熠辉 AI 编程课](https://happyaicoding.com/)** — 从真实项目出发，帮助学习者把想法做成可用产品的 AI 编程实战课程。
